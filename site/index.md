# 开始学习

Agent Learning Hub 是一个离线优先的 Agent Learning Lab。公共课程、可运行实验、个人工作簿和静态站点相互分层；核心路径不需要 API key。

## 十分钟运行第一个 Lab

```powershell
uv sync --all-extras --dev --locked
uv run pytest labs/stage-02-agent-loop/tests
```

然后打开[课程路线](generated/roadmap.md)，从 `S00` 开始，或根据现有能力选择阶段。任务完成需要概念、Lab、失败场景、自动验证和证据记录，不能只打勾。

!!! note "个人数据"
    进度与笔记只保存在当前浏览器或 `workbook/local/`。本站没有账号、云同步或追踪分析。
